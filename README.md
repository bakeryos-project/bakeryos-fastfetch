# BakeryOS Fastfetch

BakeryOS Fastfetch configuration and ASCII logo, packaged separately from the ISO and
shell defaults.

The package depends on upstream `fastfetch` and installs the BakeryOS config at
`/usr/share/fastfetch/bakeryos.jsonc` and the logo at `/usr/share/fastfetch/logo.txt`.
The shell configuration invokes this preset when Fastfetch is installed.

## Build

Build and install the package using the BakeryOS PKGBUILD in the
[`PKGBUILDS`](https://github.com/bakeryos-project/PKGBUILDS) repository.
